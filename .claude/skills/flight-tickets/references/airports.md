# Аэропорты: города с несколькими аэропортами и ловушки LCC

Когда пользователь называет город, а не аэропорт, уточни какой именно —
особенно для городов из этого списка. Коды указаны по IATA.

## Города с несколькими аэропортами

| Город | Аэропорты | Примечания |
|---|---|---|
| Москва | SVO (Шереметьево), DME (Домодедово), VKO (Внуково) | Разные концы города, между ними 1,5–2+ часа |
| Санкт-Петербург | LED (Пулково) | Один, но уточнять не нужно |
| Лондон | LHR, LGW, STN, LTN, LCY, SEN | STN/LTN — лоукостеры, далеко от центра |
| Париж | CDG, ORY, BVA (Beauvais) | BVA — 80+ км от Парижа, только автобус |
| Милан | MXP, LIN, BGY (Bergamo) | BGY — база Ryanair, ~50 км |
| Рим | FCO, CIA | CIA — лоукостеры |
| Стамбул | IST, SAW | SAW — азиатская сторона, лоукостеры |
| Нью-Йорк | JFK, EWR, LGA | EWR — Нью-Джерси; LGA — только внутренние |
| Токио | NRT, HND | HND ближе к городу |
| Дубай | DXB, DWC | DWC — редкие чартеры и LCC |
| Бангкок | BKK, DMK | DMK — AirAsia и другие LCC |
| Осло | OSL, TRF (Torp) | TRF — ~110 км от города |
| Барселона | BCN, GRO (Girona), REU | GRO/REU — Ryanair, 90–100 км |
| Берлин | BER | Единственный после закрытия TXL/SXF |
| Тбилиси | TBS | Часто дешевле лететь через KUT (Кутаиси, LCC Wizz Air) |

## Метапоиск: городские коды

У крупных агломераций есть городские коды, покрывающие все аэропорты — 
используй их в поиске, чтобы не пропустить варианты: MOW (Москва),
LON (Лондон), PAR (Париж), MIL (Милан), ROM (Рим), NYC (Нью-Йорк),
TYO (Токио), STO (Стокгольм), BUE (Буэнос-Айрес).

## Правила про лоукостеры

- Заголовочная цена LCC почти никогда не финальная: багаж, выбор места,
  регистрация в аэропорту — всё платное. Считай итог с нужными опциями.
- У Ryanair/Wizz Air онлайн-регистрация обязательна; в аэропорту — платная.
- Нормы ручной клади у LCC жёстче (часто только «сумка под сиденье»
  40×30×20), приоритетная посадка с полноценной ручной кладью — допуслуга.
- Стыковки LCC — это почти всегда self-transfer: две отдельные брони, при
  опоздании первого рейса второй пропадает без компенсации. Предупреждай.
